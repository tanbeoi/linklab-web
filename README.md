# LinkLab Web

Frontend application for **LinkLab**, a creative collaboration platform where photographers, models, videographers, and other creatives can publish collaboration opportunities, apply to projects, organise moodboards, and share completed work through galleries.

This repository contains the **Next.js frontend** for LinkLab.

- **Backend API:** [linklab-api](https://github.com/tanbeoi/linklab-api)
- **Live Application:** [linklab-web.vercel.app](https://linklab-web.vercel.app/dashboard)

---

## Overview

LinkLab is designed around the lifecycle of a creative collaboration:

```text
Collaboration Post
        ↓
Applications
        ↓
Accepted Collaborators
        ↓
Moodboard / Planning
        ↓
Gallery / Final Work
```

The frontend provides the user-facing experience for discovering projects, applying to collaborations, managing work, organising moodboards, and viewing or publishing galleries.

---

## Features

- User registration and login
- Browse collaboration posts
- Create collaboration opportunities
- Apply to projects
- Accept or reject applications
- View submitted and received applications
- Manage accepted collaborations
- Create and organise galleries
- Upload images using pre-signed Amazon S3 URLs
- Publish and unpublish galleries
- View public galleries
- View linked moodboards
- Responsive interface across desktop and mobile

## Architecture

```text
        User Browser
             |
             v
        Next.js Web App
             |
             | REST API
             v
      ASP.NET Core API
        /           \
       /             \
PostgreSQL        Amazon S3
App Data          Image Storage
```

The frontend communicates with the LinkLab API for authentication, collaboration data, applications, galleries, and image metadata.

Image files are uploaded directly to Amazon S3 using pre-signed URLs generated by the backend.

## Local Setup

### 1. Clone the repository

```bash
git clone https://github.com/tanbeoi/linklab-web.git
cd linklab-web
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file:

```env
NEXT_PUBLIC_API_URL=http://localhost:5125
```

The backend should be running locally at:

```text
http://localhost:5125
```

See the backend repository for API setup:

[github.com/tanbeoi/linklab-api](https://github.com/tanbeoi/linklab-api)

### 4. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## Authentication

The frontend stores and sends the JWT returned by the LinkLab API for authenticated requests.

Protected API calls include:

```http
Authorization: Bearer YOUR_JWT
```

Authenticated features include:

- creating posts
- applying to collaborations
- managing applications
- creating galleries
- uploading photos
- publishing galleries

---

## Image Upload Flow

LinkLab uploads images directly from the browser to Amazon S3.

```text
Frontend
   |
   | 1. Request upload URL
   v
Backend API
   |
   | 2. Return pre-signed URL
   v
Frontend
   |
   | 3. Upload image directly
   v
Amazon S3
   |
   | 4. Save image metadata
   v
Backend API
```

This avoids sending large image files through the application server.
